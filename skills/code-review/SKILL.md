# 代码审查技能

当用户要求审查代码时，按以下清单逐项检查：

1. 正确性：逻辑是否有 bug、边界条件是否处理
2. 安全：是否有注入、越权、敏感信息泄露
3. 性能：是否有不必要的重复计算、N+1 查询
4. 可读性：命名是否清晰、是否有冗余代码

输出格式：按严重程度（致命 / 警告 / 建议）分级列出问题，每个问题给出位置和改法建议。
